# 🏝️ AI 荒岛求生观察终端 (AI Survival Island)

一个运行在网页端（GitHub Pages）的纯文本、Emoji 与数值反馈的 AI 观察向小游戏。游戏内置了独立的 AI 决策大脑，能够根据自身生存状态自主做出求生选择。

## 🎮 游戏特色

- **🤖 独立 AI 玩家**：无需玩家手动介入，AI 角色会实时监控自身 ❤️ 体力、🍗 食物、💧 淡水 等生存指标。
- **📜 实时决策日志**：完整打印 AI 的思考逻辑（Reasoning）与动作选择（Action）。
- **📱 极简响应式设计**：专为手机与桌面端浏览器优化，无需任何复杂依赖，开箱即用。
- **⚡ 纯静态托管**：完全适配 GitHub Pages 静态服务器。
